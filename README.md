## ✨ 核心功能一览

### 🌐 1. Chrome 便携版极速下载与升级
*   **免翻墙直连下载**：自动匹配官方最新版本，国内网络满速直连下载，彻底告别卡顿与更新失败。
*   **多版本通道自由切换**：支持 **稳定版 (Stable)**、**测试版 (Beta)**、**开发版 (Dev)**、**金丝雀版 (Canary)** 四大分支一键切换更新。
*   **架构自动识别**：智能检测系统 64位 / 32位 架构并自动推荐最佳安装包。

### 🤖 2. 本地 AI 模型体检与彻底清理
*   **一键清除 4GB 垃圾**：智能扫描并清空 Chrome 在后台静默下载的本地大模型（Gemini Nano）缓存，瞬间释放数 GB 系统盘空间。
*   **全域 AI 功能封锁**：一键关闭标签栏“问问 Gemini”按钮、右键 AI 菜单、AI 辅助撰写及后台静默下载通道，还你纯净的浏览器界面。

### 🧹 3. 缓存写入拦截与容量上限控制
*   **禁止无用缓存写入**：可选择性封锁 GPU 着色器缓存与崩溃日志文件的生成，从源头防止磁盘空间无故膨胀。
*   **自定义缓存大小限制**：支持设置浏览器缓存上限（默认 2GB，可自由调整），超额自动循环清理。
*   **安全一键瘦身**：提供独立的缓存清理功能，仅清理临时网页图片与代码，**100% 保证密码、Cookies、书签与历史记录完好无损**。

### ⚙️ 4. 系统集成与安全防护
*   **一键接管默认浏览器**：完美支持 Win7 / Win8 / Win10 / Win11，轻松将便携版设为系统默认浏览器。
*   **桌面快捷方式管理**：一键生成或清理桌面快捷方式，支持便携模式与本地配置读取双模式。
*   **运行路径智能提醒**：自动识别运行目录，若检测在桌面、下载文件夹或系统 C 盘运行，会温柔提醒移动至非系统盘，防止重装系统丢失数据。

### 🔄 5. 升级器自身无感热更新
*   **后台静默检测**：启动时自动检测升级器自身是否有新版本，发现新版时以优雅的呼吸灯按钮提醒。
*   **一键自动热替换**：点击升级按钮后自动完成新版下载、自我替换并重新拉起，无需手动重新下载安装。

## 🛠️ 使用说明

1. **下载即用**：下载 `ChromeUpdater.exe` 后直接双击运行（绿色单文件，无额外依赖）。
2. **常规升级**：点击【检查并更新】即可自动下载解压最新 Chrome 便携版；点击【启动浏览器】即可秒开运行。
3. **日常维护**：通过【AI 模型体检】和【清理】按钮随时保持磁盘空间清爽干净。
